# Jeewoong Derm Lab

**Bridging Bench, Clinic, and Population**

This repository contains the source code for the [Jeewoong Derm Lab](https://jwchoi-derm-lab.github.io/) official website, deployed as a static site via GitHub Pages.

## About the Lab

Jeewoong Derm Lab pioneers **Translational Dermatology & Computational Biology**, integrating clinical dermatology with computational biology to advance data-driven precision dermatology. We combine nationwide health claims databases, high-throughput skin microbiome metagenomics, and advanced surgical oncology to unravel cutaneous pathology from molecular mechanisms to population scale.

### Core Research Pillars

- **Skin Microbiome & Shotgun Metagenomics** — Investigating taxonomic, functional, and strain-level dysbiosis in skin malignancies and inflammatory dermatoses using reproducible bioinformatic pipelines and metagenome-assembled genomes (MAGs).
- **Dermato-Oncology & Dermato-Surgery** — Optimizing clinical outcomes, surgical margins, and reconstructive flap designs for melanoma and non-melanoma skin cancer (NMSC) with nationwide clinical registries.
